woostack coordinates development through explicit user decisions, isolated implementation, and
independent review. Bounded fixes and changes use one-PR delivery. Build and project-backed Fix retain
complete user-verified specifications, outcome-based plans, and recovery state locally, with optional
provider mirrors. Git and GitHub prove code and pull-request state.

The [core concepts](/docs/concepts) explain the authority boundaries; the
[workflow maps](/docs/concepts/workflows) show how to choose and run each route.
[woostack-reflect](/docs/skills/woostack-reflect) suggests novel durable rules from a fixed
active-conversation snapshot and routes each finding to the narrowest applicable rule or canonical
skill owner. Local diagnostic reports remain non-authoritative evidence.
